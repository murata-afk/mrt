# 毎朝のスケジュール & ミーティングアドバイス通知

## 目的
毎朝（平日 7:00）に「その日＋翌日」の予定を集め、ミーティングごとのアドバイス
（目的・参加者・準備・注意点）を生成し、人間レビューのあと Slack に通知する。

## フロー全体
1. **情報収集**: Google Calendar（今日＋明日の予定）→ 各予定に関連する Slack / Gmail を検索
2. **アドバイス生成**: Claude が予定＋文脈を統合してミーティングごとの助言を作る
3. **人間レビュー**: チャット上で内容を確認・修正・承認
4. **通知**: 承認済みアドバイスを Slack（自分への DM または指定チャンネル）へ送信
5. **最終確認**: Slack に正しく届いたかを人間が確認

## 採用ツール（すべて Claude 標準コネクタ = インストール不要）
| 用途 | 採用 | 状態 |
|---|---|---|
| 予定取得（今日＋明日） | Google Calendar コネクタ | ✅ 接続済み |
| 予定に関連する会話の検索 | Slack コネクタ | ✅ 接続済み |
| 予定に関連するメール検索 | Gmail コネクタ | ✅ 接続済み |
| 通知の送信先 | Slack コネクタ（DM / チャンネル） | ✅ 接続済み |

Slack コネクタは 2026-01 に一般提供。読み取り（検索・履歴）と送信の両方に対応。

## 段階的ロードマップ
| Phase | やること | 難易度 | 効果 |
|---|---|---|---|
| 1 | Calendar（今日＋明日）→ アドバイス生成 → レビュー → Slack へ手動送信 | ★ | ★★ |
| 2 | 各予定に紐づく Slack / Gmail の文脈を自動で足してアドバイスを厚くする | ★★ | ★★★ |
| 3 | 毎朝 7:00 の自動実行（Routine/cron）＋定型レビュー導線 | ★★★ | ★★★ |

## Phase 1 の詳細（半日で動くレベル）
- **入力**: なし（当日実行時の日付を基準に「今日」「明日」を自動判定）
- **処理**:
  1. `mcp__Google_Calendar__list_events` で今日 00:00〜明日 23:59 の予定を取得
  2. 予定ごとに要点（時刻・件名・参加者・場所/オンライン）を整理
  3. Claude が「目的の推測 / 準備すべきこと / 注意点」を 1 件ずつ生成
  4. チャットに一覧表示 → 人間が確認・修正・承認
  5. 承認後 `mcp__Slack__slack_send_message`（送信先は下記）で通知
- **通知先**: まずは「自分への Slack DM」推奨（他人に見えず安全にテストできる）
- **完了判定**: 自分の Slack DM に、今日＋明日の予定アドバイスが 1 通届く

## 安全設計（誤通知の防止）
- Slack への送信は **人間の承認後のみ**。承認前は `slack_send_message_draft`（下書き）に留める選択肢もある
- Phase 1〜2 は「読み取り」中心。カレンダーへの書き込み・予定変更は一切しない
- 自動化（Phase 3）でも送信直前に必ずレビュー導線を挟む
