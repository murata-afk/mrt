# 8M コンテナ型DC 全国展開スキーム構想

> 作成日: 2026-08-24 / ステータス: **たたき台（意思決定前）**
> 本書は事業構想の検討材料であり、税務・法務の確定見解ではない。税制の適用可否は必ず税理士法人・弁護士のオピニオンで確定させること（後述「落とし穴」参照）。

---

## 0. 前提の整理（ここが設計の出発点）

本書は以下を前提に置く。異なる場合は結論が変わるので最初に潰すこと。

| # | 前提 | 確認要否 |
|---|---|---|
| P1 | 8M はコンテナ型DCを**設計・製造・据付・運用できる**（技術と人はある） | ★確認 |
| P2 | 8Mグループには**自己資金も借入余力もほぼない** | 所与 |
| P3 | 8M自身の**課税所得は小さい**（＝減税の受け皿になれない） | ★確認 |
| P4 | 1棟あたり投資額は**1〜3億円規模**（躯体+電源+空調+IT機器） | ★確認 |
| P5 | アンカーとなる**需要（顧客）はまだ確定していない** | ★確認 |

### 最重要の論点

> **設備投資減税の便益は「その設備を取得し、自らの事業の用に供する者」にしか帰属しない。**

即時償却も税額控除も、**課税所得がある者**にしか価値がない。8Mが取得者になった瞬間、減税メリットは繰越欠損金として塩漬けになり、現在価値はほぼゼロになる。

したがって設計原理はひとつ。

> ### 減税メリットを「8Mが受け取るもの」ではなく、**「資金を出すパートナーへ払う対価（通貨）」**として設計する。
> 8Mが出すのは**資本ではなく、案件・技術・運営・顧客**。

「金がない」は弱点ではない。**アセットライトで全国展開する必然性**として使える。太陽光、トランクルーム、コインランドリー、ホテルはすべてこの構造で全国展開した。

## 1. 誰がバランスシートを出すか — 3つの型

| | **型A: 地域オーナー分譲型** | **型B: リース会社型** | **型C: SPC/ファンド型** |
|---|---|---|---|
| 資産保有者 | 地方の高収益オーナー企業 | リース会社 | GK（合同会社）SPC |
| 減税の受け皿 | オーナー企業 | リース会社 / 借手（要設計） | TK出資者・SPC |
| 8Mの役割 | EPC + 運営受託 + 送客 | EPC + オペレーター | AM/オペレーター + 少額出資（5〜10%） |
| 8Mの初期資金 | **ゼロ** | ゼロ（リース料は固定費） | 小（GP出資のみ） |
| 1件の規模 | 1〜3億（1〜数棟） | 1〜5億 | 10〜50億（複数棟バンドル） |
| 立ち上げ速度 | **速い（3〜6ヶ月）** | 速い | 遅い（12〜18ヶ月） |
| 全国展開の乗数 | **高（横展開しやすい）** | 中 | 低（案件が重い） |
| 主リスク | 節税商品化・稼働率 | リース料が固定費化 | 組成コスト・出口 |
| **推奨** | **本命（Phase 1-2）** | 併走（標準化の受け皿） | Phase 3（大型化・出口） |

### 推奨: 型A を本命に、型B を併走させ、実績が溜まったら型C へ

型Aで「1棟モデル」を量産し、型Cで「まとめて売却（出口）」を作る。型Bはオーナーが見つからない地域の埋め合わせ。

## 2. 本命スキーム: 地域オーナー分譲型（1棟オーナー制）

### 2.1 構造

```
   【地域オーナー企業】                    【8M】
   ・課税所得 1〜10億/年                   ・技術/EPC
   ・遊休地・遊休工場・受電設備あり          ・運営ノウハウ
   ・節税ニーズが強い                       ・顧客チャネル
         │                                    │
         │ ①コンテナDC を発注・取得            │ ②建設・据付（EPCマージン）
         │   （所有者＝オーナー）              │
         ▼                                    │
   ┌─────────────────────────┐              │
   │  コンテナDC（1棟＝300kW〜1MW）  │◀────────┘
   │  ・機械装置/器具備品/建築物      │  ③運営を8Mへ業務委託
   │  ・オーナー名義で資産計上         │    （※賃貸借にしない = 最重要）
   └─────────────────────────┘
         │ ④コロケーション/GPUクラウド役務提供
         ▼
   【エンドユーザー】自治体 / 大学 / 製造業エッジAI / SIer / GPU事業者
         │
         └─▶ 売上 ── オーナー取分（例70%） / 8M運営フィー＋レベニューシェア（例30%）
```

### 2.2 各者の取り分（例示・要差し替え）

**オーナー側の経済性（投資2.0億円、実効税率33%と仮定）**

| 項目 | 金額イメージ | 備考 |
|---|---|---|
| 投資額 | 2.0億円 | 躯体・電源・空調 1.0億 + IT機器 1.0億 |
| 初年度 即時償却による税繰延 | 約 6,600万円 | ※**繰延であって減税ではない**。恒久効果は税額控除（例10%＝2,000万円） |
| 償却資産税の軽減（3〜5年） | 年 100〜250万円 | 先端設備等導入計画による特例 |
| 稼働後の年間役務収入（オーナー取分） | 年 3,000〜5,000万円 | 稼働率・単価に強く依存 |
| 土地取得コスト | **0円** | 自社遊休地を使う前提 = これが効く |

→ **「節税」だけで売らない。節税は入口のフックで、本体は稼働収益。** 節税単体で売ると否認リスクとレピュテーションリスクを背負う（後述）。

**8M側の経済性（1棟あたり）**

| 収益源 | タイミング | イメージ |
|---|---|---|
| EPCマージン | 引渡時 | 投資額の 15〜25% |
| O&M固定フィー | 毎月 | 月 50〜150万円 |
| レベニューシェア | 毎月 | 役務収入の 20〜35% |
| 顧客送客手数料 | 契約時 | 初年度契約額の数% |

**8Mは1棟あたり自己資金ゼロで、引渡時にキャッシュインし、その後ストック収益が積み上がる。** 100棟展開してもBSはほぼ膨らまない。

### 2.3 【最重要】契約形態は「賃貸借」ではなく「業務委託」にする

中小企業経営強化税制などの即時償却・税額控除は、**「貸付けの用に供する資産」を対象から除外**している（実務上の頻出論点）。

- ❌ オーナーがDCを取得 → **8Mに賃貸** → 8Mが顧客に売る
  → オーナーにとって「貸付けの用に供する資産」となり、**減税が飛ぶ可能性**
- ✅ オーナーがDCを取得 → **オーナー自身がDC事業者**として顧客に役務提供 → **8Mは運営を受託**
  → オーナーは自らの事業の用に供している。8Mは業務委託先。

この一点でスキーム全体の成否が変わる。契約書は**賃貸借契約ではなく、運営業務委託契約 + 成果連動フィー**で組む。あわせて、顧客との契約主体をオーナーにする（8Mは代理店/取次）。

※ ただし「実質は賃貸ではないか」と見られない実態づくりが要る（顧客との契約名義、リスク負担、価格決定権の所在）。ここは必ず事前に税理士法人の見解を取る。

## 3. どんなパートナーを探すか — 役割別ロングリスト

パートナーを「金」で一括りにしないこと。全国展開に必要な資源は4つに分解できる。

### ① 土地 + 電力 を持つ人 ← **実は最大のボトルネックはここ**

全国展開の実体は「**高圧・特高の空き容量がある場所を押さえる競争**」。土地は余っているが電力は余っていない。

| 候補 | なぜ刺さるか |
|---|---|
| **遊休工場・減産工場を持つ製造業** | 既存の高圧/特高受電設備が余っている。基礎・耐荷重・排熱の素地あり。しかも高収益＝節税ニーズもあり、**①と②を兼ねる最強の相手** |
| 倉庫・物流不動産会社 | 床耐荷重、電源、全国拠点網 |
| 太陽光・バイオマス・小水力事業者 | FIT終了後の余剰電力の出口を探している。オフサイト/オンサイトPPAと組める |
| 地域新電力・都市ガス（コージェネ） | 電力調達をパートナー側で完結できる |
| CATV・地域ISP・放送局 | 局舎・回線・空調のノウハウ。地域の法人顧客も持つ |
| 自治体（廃校・工業団地・過疎地域） | 企業立地補助金、固定資産税の不均一課税、地域未来投資促進法の承認 |

### ② 課税所得（＝減税を使い切れる利益）を持つ人

| 候補 | アプローチ |
|---|---|
| **地方の高収益オーナー企業** | 建設・不動産・運送・食品・医療法人・農業法人など。決算対策ニーズが毎年発生する |
| **地銀・信金 + そのリース子会社/投資子会社** | ← **全国展開の乗数。詳細は §4** |
| リース大手 | 東京センチュリー / 芙蓉総合リース / SMFL / 三菱HCキャピタル / NTT・TCリース / JA三井リース など。DC・再エネへの投資意欲が高い |
| 総合商社 | 伊藤忠・丸紅・双日・兼松など。BS と全国顧客網。ただし意思決定は遅い |
| 上場事業会社（本業が好調で節税ニーズ） | CVC経由で入ることも |

### ③ 需要（アンカーテナント）を持つ人 ← **資金より先に押さえるべき**

> **「金がない」の本当の解は「契約がある」。** 10年の長期契約が1本あれば、それを裏付けにノンリコースで資金は付く。順序を間違えないこと。

- 自治体クラウド / ガバメントクラウドの周辺、地域医療情報連携
- 大学・研究機関（GPU需要、科研費・大型予算）
- 製造業のエッジAI・画像検査（低レイテンシで現場に置きたい）
- GPUクラウド事業者・AIスタートアップ（都心の電力が取れず地方を探している）
- SIer・地場システム会社（NTTデータ、TIS、大塚商会、地場SIer）
- 放送・映像制作・ゲーム

### ④ 技術・供給・公的支援

- GPU/サーバーベンダーの販売金融（ベンダーファイナンス）
- 空調（液冷）・非常用発電・UPS・変圧器メーカー
- 通信キャリア（閉域網・ダークファイバ）
- 公的: 経産省/NEDO の地方DC整備系補助金、地域未来投資促進法の承認、日本政策投資銀行（DBJ）、商工中金、日本公庫、REVIC・地域ファンド

## 4. 全国展開の乗数は「地銀チャネル」

8Mが1社ずつオーナーを探すのは非効率。全国に一気に広げる唯一の現実解は**地方銀行との提携**。

地銀は 8M が欲しいものを全部持っている:

1. **地元の高収益オーナー企業の名簿**（誰が今期儲かっていて節税したいかを知っている）
2. **法人営業が売る「提案ネタ」への飢え**（低金利で貸出だけでは差別化できない）
3. **リース子会社・投資専門子会社**（自行でファイナンスを組める）
4. **地域活性化・事業性評価のKPI**（金融庁対応としてストーリーになる）
5. 地元自治体・電力へのアクセス

**提携の形**: 8Mが「1棟パッケージ商品」を作り、地銀の法人営業が販売。8Mは紹介手数料を払い、建設と運営を担う。
1行あたり年5〜10棟なら、10行で年50〜100棟。これが全国展開の現実的な絵。

同じ構造で **信金中央金庫・全国信用金庫協会、地銀リース子会社連合、商工会議所** にも横展開できる。

## 5. 使える可能性のある税制・支援（※要最新確認）

> ⚠️ 税制は毎年改正される。以下は「候補の棚卸し」であり、**適用年度・要件・存続を必ず最新の税制改正大綱と税理士で確認すること**。特に適用期限切れに注意。

| 制度 | 効果（目安） | 誰が使うか | 論点 |
|---|---|---|---|
| **中小企業経営強化税制** | 即時償却 or 税額控除7〜10% | オーナー企業 | **①「貸付けの用に供する資産」除外 ②経営力向上計画の認定は原則「取得前」** |
| 中小企業投資促進税制 | 30%特別償却 or 7%税額控除 | オーナー企業 | 中小企業者等の要件 |
| **先端設備等導入計画（固定資産税特例）** | 償却資産税 1/2〜ゼロ（3〜5年） | オーナー企業 | 市町村の導入促進基本計画が必要。自治体差が大きい |
| **地域未来投資促進税制** | 特別償却40%（建物20%）/ 税額控除4%（2%） | 中堅・大企業も可 | 都道府県の地域経済牽引事業計画の承認。**建物・構築物も対象なので大型に効く** |
| カーボンニュートラル/脱炭素系投資促進税制 | 特別償却・税額控除 | オーナー / SPC | 再エネ併設・高効率（液冷・高COP空調）で狙う |
| オープンイノベーション促進税制 | 出資額の25%所得控除 | **8Mに出資する事業会社** | 8Mへのエクイティ調達の口説き文句になる |
| エンジェル税制 | 個人投資家の所得控除 | 個人投資家 | 同上（8Mが要件を満たすか要確認） |
| 経産省/NEDO 地方DC整備系補助金 | 補助率 1/2 等 | SPC / オーナー | 公募時期が限られる。**Phase 1 のうちに採択実績を作りたい** |
| 自治体の企業立地補助金・不均一課税 | 数千万〜数億 / 固定資産税減免 | オーナー / SPC | 過疎地域・条件不利地域ほど厚い |

### 減税の「使い分け」の勘所

- **即時償却は減税ではなく繰延**。オーナーが毎年安定して黒字なら効果は限定的（将来の償却費が消えるだけ）。**今期だけ特別利益が出たオーナー**（不動産売却、M&A益、一過性の受注）に最も刺さる。
- **税額控除は恒久的な減税**。長期保有前提のオーナーにはこちらの方が有利なことが多い。
- **どちらが有利かはオーナーの利益プロファイル次第。1棟パッケージには両パターンのシミュレーションシートを標準添付する。**

## 6. 落とし穴（ここで事故る）

| # | リスク | 対策 |
|---|---|---|
| R1 | **「節税商品」化して税務否認・レピュテーション毀損** — 航空機リース、保険節税の前例あり | 事業実態（稼働率・第三者顧客・価格の独立性）を必ず担保。節税は副次的効果として提示し、主たる訴求にしない |
| R2 | **「貸付けの用に供する資産」除外に抵触** | §2.3 の業務委託スキーム。事前に税理士法人のオピニオンレターを取得 |
| R3 | **コンテナが「機械装置」か「建築物」か** — 基礎に定着させると建築基準法上の建築物になり、建築確認・耐用年数長期化・適用税制が変わる | 設計段階で建築士・税理士に同時確認。**可搬性を担保する設計**と、定着型設計の2ラインを持つ |
| R4 | **経営力向上計画の認定タイミング** — 原則、設備取得**前**に認定が必要 | 営業プロセスに「認定申請」を必須ゲートとして組み込む。段取りミスで減税が丸ごと飛ぶ |
| R5 | **稼働率リスクを8Mが実質的に負ってしまう** — オーナーに利回り保証をすると、実質ファイナンスと見なされオフバランスにならない／引当が必要 | 保証は付けない、または上限付き・期間限定に。代わりにレベニューシェアで利害を一致させる |
| R6 | **新リース会計基準（2027年4月〜適用予定）** によりオフバランス効果が縮小 | 型Bの設計に織り込む。中小企業会計指針適用会社は対象外の見込みだが要確認 |
| R7 | **電力が取れない** — 高圧受電の空き容量、系統連系の待ち行列 | 用地選定の第一条件を「電力」にする。土地から探さない |
| R8 | **中小企業者等の要件** — 資本金1億円超、大規模法人の子会社等は対象外 | オーナー候補のスクリーニング項目に入れる |
| R9 | **GPUの陳腐化** — IT機器を即時償却しても、3年で価値が消える | IT機器は別勘定・別スキーム（型B/リース）にして躯体と切り離す |

## 7. ロードマップ

### Phase 0（0〜6ヶ月）: 「売れる1棟パッケージ」を作る
- [ ] 標準1棟の BOM・原価・工期・電力要件・想定稼働率を確定
- [ ] **オーナー向け経済性シミュレーター**（即時償却型 / 税額控除型 の2本立て、税引後IRR表示）
- [ ] **税理士法人のオピニオンレター取得**（§2.3 のスキームの適法性）
- [ ] 建築基準法上の扱いを設計で確定（R3）
- [ ] 契約書ひな型一式（運営業務委託、レベニューシェア、顧客契約）
- [ ] アンカーテナント候補 5社へのヒアリング（需要の実在確認）

### Phase 1（6〜18ヶ月）: パイロット 2〜3拠点
- [ ] **型Aで1拠点**（遊休工場を持つ製造業オーナーが最有力）
- [ ] **型Bで1拠点**（リース会社と組成）
- [ ] 補助金1本の採択実績を作る（地方DC整備系 or 自治体立地補助）
- [ ] 稼働率・PUE・実原価の実績データを取る ← **これが次フェーズの資金調達の担保**

### Phase 2（18〜36ヶ月）: 地銀チャネルで全国へ
- [ ] 地銀 3〜5行とマスター提携（商品化・紹介手数料・研修）
- [ ] 標準化された営業キット（提案書・シミュレーター・申請代行）
- [ ] 目標: 年 30〜50棟

### Phase 3（36ヶ月〜）: 型Cで大型化・出口
- [ ] 複数棟をバンドルしてSPC化、ノンリコースファイナンス
- [ ] 私募REIT / インフラファンドへの売却で出口を作る
- [ ] 8Mはオペレーター/AMとしてフィーとプロモートを取る

### 追うべきKPI
| KPI | 意味 |
|---|---|
| 契約済み電力容量（MW） | 事業規模の本質的な指標 |
| 棟あたり稼働率と満床までのリードタイム | 経済性の生命線 |
| 8M自己資金投下額 / 総投資額 | **アセットライト度合い。低いほど良い** |
| ストック収益（O&M+レベシェア）の月次残高 | 企業価値の源泉 |
| 地銀チャネル経由の案件比率 | 全国展開の乗数が効いているか |

## 8. 直近90日でやること（優先順）

1. **需要の実在を確認する** — アンカーテナント候補への当て込み。ここが空なら他は全部絵に描いた餅。
2. **オーナー候補を1社見つける** — 「遊休工場 + 高収益 + 節税ニーズ」の三拍子。取引金融機関からの紹介が最短。
3. **税務スキームを確定する** — §2.3 と R2/R3/R4。オピニオンレターまで取る。
4. **経済性シミュレーターを作る** — オーナーが「自社の決算数値」を入れて税引後IRRが出るもの。これが営業の武器。
5. **地銀1行と初回面談** — 商品化の可能性を打診。Phase 2の布石。

## 9. 補足: 8M自身の資金調達（スキームと並行して）

全国展開の運転資金（人件費・先行開発費）は別途要る。アセットは持たなくても、組織は先行投資が必要。

- **オープンイノベーション促進税制**を使い、事業会社（商社・リース・電力・SIer）からの出資を引く（出資側に25%所得控除のメリット）
- 上記パートナー候補との**資本業務提携**（金だけでなく案件・顧客がセットで来る相手を優先）
- EPCマージンの前受け・出来高払いで運転資金の持ち出しを最小化
