### 読み取れる5つのこと

**① IRR 17.2% は「アンレバード（借入なし）のプロジェクトIRR」**
フリーCFベースと明記されている以上、これは借入を入れる前の数字。**日本の調達金利が2〜3%なら、スプレッドは14ポイント以上ある。** これはプロジェクトファイナンスが最も効く条件そのもの。

**② 資産回転率が異例に高い（売上22.6億 ÷ 投資21億 ＝ 1.08）**
通常のコロケーションDCは0.2〜0.3。1.08が成立するのは売上の58%がホスティング（GPU時間の販売）だから。GPUクラウドは回転が速い。ただしこれは**GPUが常時売れている前提**であり、稼働率が事業の生命線。ここが計画の最も脆い部分。

**③ 販管費が売上の36%（808 ÷ 2,257）**
DC事業としては極めて高い。営業組織やグループ配賦が入っていると思われる。中身の内訳と、拠点数が増えたときにスケールするのか（固定費なのか拠点比例なのか）を確認すべき。**ここが固定費なら、2拠点目以降のIRRは17.2%より大幅に良くなる。**

**④ 再CAPEX（GPU更新）を織り込んでいるのは誠実**
198／57／77。多くのAI DC計画はこれを落として見栄えの良いIRRを出す。入れてある点は投資家に対する強みなので、むしろ前面に出すべき。ただし2MW分のGPU更新として198百万が十分かは要検証。

**⑤ 土地造成11億が毎年1.14億の償却を生むが、売上は1円も生まない**
これが次章。

## 2. 最大の発見 ── 土地造成11億がIRRを殺している

投資総額21億の内訳（資料 p.22）:

| 大分類 | 中分類 | 金額 |
|---|---|---|
| **土地造成関係** | 電気工事（電力引込、高圧線、キュービクル等） | 3億円 |
| | 冷却工事（地下水工事もしくはチラー） | 2億円 |
| | 外構工事（60cm基礎、電気・水道引き回し、セキュリティ、UPS、自家発電） | 6億円 |
| | **小計** | **11億円** |
| **コンテナDC関係** | DC開発一式（コンテナ、液浸ラック、消火設備、NW機器） | 10億円 |
| | **総額** | **21億円** |

> **投資額の52%が「土台」に消えている。** 通常のDCは電気・機械設備が支配的で、土木造成がここまで大きいのは異常。これは事業の構造的欠陥ではなく、**立地の選び方の問題**である可能性が高い。

### 資料 p.14 に答えが書いてある

自社モデルの導入プロセスとして「**空き工場・倉庫 → 電源接続 → コンテナ設置**」と明記されている。この強みを、立地選定の第一原則にまで徹底すべき。

**狙うべきは「電力多消費産業の遊休・減産工場」。** 製紙（抄紙機停止）、化学、繊維、アルミ・電炉、造船、半導体旧ライン、セメント。これらは液浸AI DCが必要とするものをすべて既に持っている:

| 必要なもの | 電力多消費工場が既に持っているもの | 削れる費用 |
|---|---|---|
| 高圧・特高受電、キュービクル | 稼働時の受電設備がそのまま残っている | 電気工事 3億 → **0.5〜1億** |
| 冷却水（液浸の二次側） | 工業用水・井戸・取水権・受水槽 | 冷却工事 2億 → **0.3〜0.5億** |
| 重量物に耐える床・基礎 | 大型機械用の厚床・堅牢基礎 | 外構（基礎） |
| 構内セキュリティ・守衛 | フェンス・門・守衛所 | 外構（セキュリティ） |
| | | 外構工事 6億 → **2〜3億** |
| | **土地造成 11億 → 3〜4.5億** | **約7億の削減** |

※ UPS・自家発電は新設が必要なので外構の全額は消えない。

### IRRへの影響（概算）

フリーCFをほぼ不変（減価償却は非現金費用）とすると:

| ケース | 投資総額 | 概算IRR |
|---|---|---|
| 現行計画（更地・新規造成） | 21億 | **17.2%** |
| 遊休工場活用 | 14億 | **約26〜29%** |
| ＋ 補助金 2〜3億 | 11〜12億 | **約33〜38%** |

※ 償却減による税シールドの喪失分を控除した粗い試算。実モデルで再計算のこと。

> ### **どんな資金調達スキームより、立地選定の方が効く。**
> 11億を誰かに出させる交渉より、11億を要らなくする立地を選ぶ方が速く、確実で、交渉相手にも喜ばれる。

そしてこの立地戦略は、そのまま**パートナー戦略**でもある。遊休工場を持つ企業は、土地・電力・水・堅牢基礎に加えて、**課税所得（＝減税の受け皿）**と**自社のAI需要（＝アンカーテナント）**まで持っている。8Mが必要とするものを、ほぼ全部ひとりで持っている唯一の相手。

## 3. 21億を一体で売るな ── レイヤード・キャピタルスタック

21億を「ひとつの投資案件」として誰かに買わせようとすると、誰も買えない。**中身のリスクプロファイルがまったく違う3つの資産が混ざっているから。**

| 層 | 内容 | 金額 | 資産の性格 | 耐用 | 最適な出し手 |
|---|---|---|---|---|---|
| **L1 インフラ層** | 土地・造成・受変電・基礎・外構 | 11億<br>（→3〜4.5億） | 不動産的・移動不可 | 15〜40年 | 遊休工場オーナー（現物出資）、地元ゼネコン/サブコン（工事出来高出資）、自治体補助、地銀、不動産・インフラファンド |
| **L2 モジュール層** | コンテナ、液浸ラック、消火、NW機器 | 10億 | 動産・可搬・標準化可能 | 7〜15年 | **リース会社**、商社、地銀リース子会社 |
| **L3 計算資源層** | GPU・サーバー | L2内 or 別建て | 陳腐化が速い・残価が読めない | 3〜5年 | ベンダーファイナンス、GPU専門ファイナンス、**国の計算資源補助**、レベニューシェア |

**なぜこれが効くか。** 不動産屋は不動産を買う。リース会社は動産をリースする。ベンダーは自社製品にファイナンスを付ける。**それぞれにとって「いつもの案件」の形で切り出せば、審査は通る。** 3つを束ねた「AI DC 21億」という得体の知れないものを持ち込むから止まる。

物流施設、太陽光、ホテルはすべてこの分解で資金を集めている。

### L2をリースにする副次効果 ── 8Mの現金が「入る」

コンテナDC 10億をリース会社が保有するなら、リース会社は**New Rule Lab から10億でKAMUIを購入する**。

> **8Mグループにとって、これは支出ではなく売上。**
> 「金がない会社がDCを建てる」話ではなく、「**製造業がDCを売る**」話に変換される。

これが構造の核心。§7で詳述する。

## 4. パートナー設計 ── 資料の相手（ゼネコン）へのアプローチを変える

資料 p.22 に「土地造成部分の11億円程度は、御社の専門領域と捉えており」とある。この資料はゼネコン／サブコン／土木の専門会社に向けたものと読める。

### 今の提案は「工事を発注します」で止まっている

それでは資金の話にならない。ゼネコンは受注しても、**8Mが21億を用意できなければ着工しない。**

### ゼネコンを「工事業者」ではなく「エクイティパートナー」にする

建設業界ではPFI／PPPで普通に行われている形。**工事代金の一部を出資に振り替える（Contractor Equity）。**

ゼネコン側の合理性:
- **11億の工事を、営業コストゼロで確実に受注できる**
- 施工者利益（工事の10〜15%＝1〜1.6億）が実質的に出資のディスカウントになる。3億出資しても、実質的な持ち出しは1.5〜2億
- 出資分は将来のリターン（プロジェクトIRR17.2%、レバレッジ後のエクイティIRRはさらに上）
- 建設会社は課税所得が大きく、**減税の受け皿として最適**
- 全国の地場ゼネコンとのネットワークが、そのまま横展開チャネルになる

**交渉の言い方を変えるだけ。** 「11億の工事をお願いしたい」→「**11億の工事を確実にお渡しします。その代わり3億を出資してください**」。

### 遊休工場オーナーには「現物出資」を

土地・建屋・受電設備・工業用水利権を**現物出資**してSPCの持分を取る。**キャッシュを1円も出さずに出資者になれる。** 遊休資産の有効活用は多くの製造業の経営課題であり、売却より出資の方が「事業として関わり続けられる」ぶん受け入れられやすい。

### 結果 ── 誰も大きな現金を出さずに拠点が建つ

| 資金の出し手 | 出すもの | 金額イメージ |
|---|---|---|
| リース会社 | 現金（L2コンテナを購入・保有） | 10億 |
| 遊休工場オーナー | 土地・建屋・受電設備の現物出資 | 2〜3億相当 |
| 地元ゼネコン | 工事出来高の一部を出資に振替 | 1〜2億 |
| 自治体・国 | 立地補助金・地方DC補助 | 2〜3億 |
| 金融機関 | ノンリコースローン（アンカー契約担保） | 残り |
| **8Mグループ** | **技術・EPC・運営・顧客** | **現金 ほぼゼロ** |

## 5. 税制・補助金の再設計（21億規模）

### ⚠️ 最重要の構造的トレードオフ

> **「大口パートナーに出資してもらう」と「中小企業向け税制を使う」は、そのままでは両立しない。**

中小企業経営強化税制・中小企業投資促進税制は**資本金1億円以下の中小企業者等**が要件で、かつ**大規模法人の子会社等は除外**される。ゼネコン・商社・リース会社がSPCの株主に入った瞬間、要件を外れる可能性が高い。

**解き方は2つ。**

**解A ── 匿名組合（TK）出資で受ける**
TK出資は資本ではないため、SPCの資本金と株主構成に影響しない。**資本金1億円以下のSPCを維持したまま、大口資金を受け入れられる。** ただしTK分配の損益取扱い・営業者要件は要確認。

**解B ── そもそも大企業も使える税制に寄せる**
**地域未来投資促進税制**は資本金要件がなく、**建物・構築物も対象**（特別償却20%／税額控除2%、機械装置は40%／4%）。**土地造成11億に効く数少ない制度**であり、21億規模ならこちらが本命。都道府県の地域経済牽引事業計画の承認が必要。

### 制度の棚卸し（※適用年度・存続は要最新確認）

| 制度 | 効果 | 誰が使うか | 8Mにとっての論点 |
|---|---|---|---|
| **地域未来投資促進税制** | 特別償却 機械40%／建物20%、控除 4%／2% | SPC・オーナー（大企業可） | **本命。土地造成11億に効く。**都道府県の承認が前提 |
| 中小企業経営強化税制 | 即時償却 or 控除7〜10% | 資本金1億円以下のSPC | 大口出資と両立しない → TK出資で回避（解A） |
| **先端設備等導入計画** | 償却資産税 1/2〜ゼロ（3〜5年） | SPC | 2MW分の機械装置に効く。市町村の基本計画が前提 |
| **カーボンニュートラル／GX系** | 特別償却・税額控除 | SPC | **液浸のPUEは空冷比で圧倒的。8Mの技術的強みが直接税メリットになる稀なケース（後述）** |
| 経産省 地方DC整備系補助金 | 補助率 1/2 等 | SPC | 2MW/21億はまさに対象規模 |
| **国の計算資源（GPU）調達支援** | 補助率 1/2〜1/3 | 8M Labs / SPC | **減税より遥かにインパクトが大きい（後述）** |
| 自治体 企業立地補助・不均一課税 | 数千万〜数億／固定資産税減免 | SPC | 21億投資・雇用・税収は自治体にとって大型案件 |
| オープンイノベーション促進税制 | 出資額の25%所得控除 | **8Mへ出資する事業会社** | グループのエクイティ調達の口説き文句 |

### 減税より先に取りに行くべきもの

**① 国の計算資源（GPU）調達支援 ＞ どんな減税**
売上の58%（13.07億）がホスティング事業＝GPU時間の販売。その原資であるGPU調達に補助率1/2〜1/3が付けば、**投資額と再CAPEXの両方が同時に軽くなる。** 減税は税率分（最大33%）の効果だが、補助金は投資額そのものが減る。**認定クラウド事業者の枠を取りに行く価値が最も高い。**

**② 液浸を「省エネ設備」として制度に載せる**
フル液浸のPUEは空冷（1.5〜1.7）に対して劇的に低い。この差は**測定でき、証明でき、金額に換算できる**。GX／カーボンニュートラル系の税制と補助金は「省エネ効果の定量化」を要求するが、8Mはそれを最も出しやすい立場にいる。**技術的優位が、そのまま税務・補助金上の優位に翻訳できる。** 京都AI Model Cityでの実測値を、この証憑として設計しておくべき。

### 減税の位置づけ ── ブースターであって燃料ではない

**プロジェクトIRRが17.2%あるなら、減税がなくても投資家はつく。** 減税は「17.2%を20%超に見せる」ためのブースター。特にL2コンテナDC 10億の初期償却は初年度のキャッシュフローを前倒しするため、IRRという時間価値に敏感な指標には効く。

**この順序を間違えないこと。** 「減税ありきのスキーム」は税務否認とレピュテーションリスクを呼び込む。8Mが売るべきは事業性であり、減税はその付属品。

## 6. KAMUI分譲モデル ── v1のスキームはここで生きる

2MW/21億の拠点は分譲に向かないが、**小型液浸AI DC「KAMUI」（New Rule Lab が開発・製造・販売）** はサイズ次第で成立する。

- 1台数千万〜2億円台なら、**中小企業経営強化税制の即時償却／税額控除が現実に使える**（資本金1億円以下のオーナー企業が買える価格帯）
- 買い手は「工場のすぐそばで低遅延の推論を回したい製造業」＝資料 p.6 の主張そのもの
- **オーナーが自社工場で自社のフィジカルAIに使う**なら、「貸付けの用に供する資産」除外の問題も起きない（自ら事業の用に供している）
- 2MW拠点への入口商品になる。KAMUIで小さく試した顧客が、拠点のテナントに育つ

### 2階建てのプロダクト戦略

| | KAMUI（分譲） | 2MW拠点（SPC） |
|---|---|---|
| 単価 | 数千万〜2億円台 | 21億円 |
| 買い手 | 製造業オーナー企業（自社利用） | SPC（複数投資家） |
| 税制 | 中小企業経営強化税制（即時償却） | 地域未来投資促進税制 |
| 8Mの収益 | 製造売上＋保守 | EPC＋AMフィー＋レベシェア |
| 役割 | **入口・量産・キャッシュ製造機** | **拠点・ストック収益** |

## 7. 8Mグループは既に正しい形をしている

資料 p.12・p.17 のグループ構成を読むと、**必要な器はすでに揃っている。**

| 会社 | 資料上の役割 | スキーム上の役割（提案） |
|---|---|---|
| New Rule Lab | KAMUIの開発・製造・販売 | **売る側に徹する。** SPCでもリース会社でもオーナーでも、買い手が誰であれ製造利益が落ちる |
| 8M キャピタル合同会社 | AI DC | **SPCのGP／アセットマネージャー。** 複数SPCの運営受託でフィー収入 |
| 8M Labs | 需要サイド主体・超大手と取引開始 | **アンカーテナント獲得。** 長期契約がノンリコースの与信になる |
| 8M Networks / AKATSUKI / EdgeLink1 | NW・実証・セキュリティ | 実証データと標準化。京都AI Model Cityの中身 |

資料 p.12 で既に「供給サイド（New Rule Lab と 8M Capital がリード）／需要サイド（8M Labs 主体）」と分けている。**この分離は正しい。**

### 足りないのは「誰が買うのか」の設計だけ

> **8Mは「DCを持ちたい会社」ではなく「DCを売る会社」になれる。**
> 拠点が100か所に増えても、8MのBSはほとんど膨らまない。増えるのは New Rule Lab の製造売上と、8M Capital の運営フィーと、8M Labs の需要。

### ただし ── グループ内取引の透明性は外部資金の最大の関門

New Rule Lab がSPCにKAMUIを売り、8M Capital がそのSPCを運営し、8M Labs がテナントになる。**外部投資家から見れば利益相反の塊。** 資金を入れる側は必ずここを突いてくる。

対策は先回りしておくこと:
- KAMUIの販売価格に**第三者の相見積り／価格妥当性の裏付け**
- AMフィー・EPCマージンの料率を**市場水準と比較できる形で開示**
- 8M Labs のテナント契約を**第三者テナントと同条件**にする
- SPCの意思決定に**独立した第三者を入れる**

## 10. 直近90日でやること

1. **液浸GPUの残価・保証問題を潰す（R1）** — これが解けないとL2のリース化が成立せず、スキーム全体が立たない。GPUベンダー・液浸液メーカー・リース会社の3者で条件を詰める
2. **電力多消費産業の遊休工場をリストアップする（§2）** — 製紙・化学・繊維・アルミ・電炉・半導体旧ライン。特高受電が生きていて、工業用水があり、床が強い物件。**IRRを17.2%→26%以上に変える最大のレバー**
3. **国の計算資源（GPU）調達支援の要件を確認し、認定を取りに行く（§5）** — どんな減税より効く
4. **既存4拠点（京都・鹿児島・横須賀・島根）で、地域未来投資促進法の承認と自治体立地補助の可否を確認** — 既に動いている拠点があるのが最大の資産
5. **8M Labs の「超大手との取引」を長期契約に転換できるか検証** — アンカー契約が取れればノンリコースが組める
6. **ゼネコンとの交渉を「発注」から「出資＋施工」に組み替える（§4）** — 資料の相手に対して、次の面談で提示する形を変える
7. **KAMUIの分譲パッケージ化（§6）** — 中小企業経営強化税制が使える価格帯・仕様・オーナー向け税引後IRRシート
8. **財務モデルにレバレッジケースを追加する** — アンレバード17.2%に対し、借入60〜70%を入れたエクイティIRRを出す。**これが出し手への最強の資料になる**

## 付録: v1から引き継ぐ考え方

規模の前提は変わったが、以下はそのまま有効。

- **減税の便益は課税所得のある者にしか帰属しない。** だから減税メリットは、資金を出すパートナーへの対価として設計する
- **「金がない」の本当の解は「契約がある」。** 長期契約はノンリコースの与信になる
- **土地より電力が先。** 全国展開の実体は受電容量を押さえる競争
- **地銀チャネルは横展開の乗数。** ただし2MW/21億は地銀単独では重い。KAMUI分譲（§6）でこそ効く
- **「貸付けの用に供する資産」除外。** KAMUI分譲で必ず論点になる
