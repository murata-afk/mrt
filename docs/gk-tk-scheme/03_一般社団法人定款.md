# 一般社団法人●● 定款

> **【ドラフト注記】** 本書式はドラフト（雛形）であり、実際の案件では弁護士・税理士・司法書士等の専門家によるレビューが必須である。本定款は、GK-TK（合同会社・匿名組合）スキームにおける倒産隔離（オーファン化）目的で設立する一般社団法人（合同会社●●の唯一の社員となる器）を想定した参考書式にすぎず、公証人の定款認証実務・登記実務・税務上の非営利要件・各案件のストラクチャー要請に応じて必ず修正すること。本文中の `[●]` は案件ごとに確定すべき事項（名称・氏名・金額・日付・所在地等）を示す。

---

## 前文

一般社団法人及び一般財団法人に関する法律（平成18年法律第48号。以下「法人法」という。）の定めるところに従い、一般社団法人●●（以下「本社団法人」という。）を設立するため、設立時社員は本定款を作成し、以下のとおり定める。

本社団法人は、GK-TK（合同会社・匿名組合）スキームにおいて営業者たる合同会社●●（以下「本合同会社」という。）の唯一の社員として本合同会社の持分を保有・管理し、もって本合同会社の倒産隔離（オーファン化）の頂点に位置する器（ビークル）として設立されるものである。本社団法人及びその機関は、本社団法人の独立性及び本合同会社の倒産隔離の維持を最優先の行動原則とする。

---

## 第1章 総則

### 第1条（名称）
本社団法人は、一般社団法人●●と称する。
2. 本社団法人は、英文では ● ● General Incorporated Association（略称 [●]）と表示する。

### 第2条（主たる事務所）
本社団法人は、主たる事務所を [●]（[●]県[●]市[●]）に置く。
2. 本社団法人は、社員総会の決議により、従たる事務所を必要な地に設けることができる。

### 第3条（目的）
本社団法人は、次の事業を行うことを目的とし、その目的の範囲は本条各号に掲げる事項に**限定**される。
1. 本合同会社の社員としてその持分を保有し、及びこれを管理すること。
2. 本合同会社の唯一の社員として、法令及び本合同会社の定款に基づき社員としての権利を行使すること。
3. 前各号に付随・関連し、かつ本社団法人の独立性及び本合同会社の倒産隔離の維持と矛盾しない事務。

2. 本社団法人は、前項に掲げる目的を達成するために必要な範囲を超えて、他の会社の社員・株主となり、事業を営み、借入れを行い、保証を提供し、又は資産を取得・処分してはならない。

### 第4条（公告方法）
本社団法人の公告は、電子公告により行う。
2. 事故その他やむを得ない事由により電子公告によることができない場合は、官報に掲載する方法により行う。

### 第5条（非営利性・剰余金の不分配）
本社団法人は、剰余金の分配を目的としない。
2. 本社団法人は、その社員に対し、剰余金又は残余財産の分配を行わない。この規定に反する社員総会の決議は、その効力を有しない。
3. 本社団法人は、法人法及び本定款に定める非営利性を維持し、これに反する行為を行わない。

## 第2章 社員

### 第6条（社員の資格）
本社団法人の社員は、本定款の定めに賛同し、次章以下の定めに従って入社した者とする。
2. 社員の資格の得喪については、本章の定めによる。

### 第7条（入社）
本社団法人の社員となろうとする者は、所定の入社申込書を提出し、社員総会の承認を得なければならない。
2. 設立時社員は、本社団法人の成立と同時に社員となる。

### 第8条（経費の負担）
社員は、本社団法人の目的である事業を遂行するために必要な経費を負担する義務を負う。負担の金額及び方法は、社員総会の決議により定める。
2. 社員は、退社の際、既に納入した経費その他の拠出金品の返還を請求することができない。

### 第9条（退社）
社員は、次の各号のいずれかに該当する場合には退社する。
1. 本人が退社を申し出たとき（ただし、本合同会社の倒産隔離維持のため、社員が1名を下回る結果となる退社は、後任社員の入社が確定した後でなければ効力を生じない。）。
2. 死亡し、又は解散したとき。
3. 総社員の同意があったとき。
4. 除名されたとき。

### 第10条（除名）
社員が次の各号のいずれかに該当する場合、社員総会の特別決議によりこれを除名することができる。
1. 本定款その他の規則に違反したとき。
2. 本社団法人の名誉を毀損し、又は目的に反する行為をしたとき。
3. その他除名すべき正当な事由があるとき。

### 第11条（社員の地位の譲渡）
社員は、その地位を他に譲渡することができない。ただし、社員総会の承認を得た場合は、この限りでない。

## 第3章 社員総会

### 第12条（構成・権限）
社員総会は、全ての社員をもって構成する。
2. 社員総会は、法人法に規定する事項及び本定款で定める事項に限り決議をすることができる。

### 第13条（種類・招集）
社員総会は、定時社員総会及び臨時社員総会とする。
2. 定時社員総会は、毎事業年度終了後3か月以内に招集する。
3. 臨時社員総会は、必要がある場合に随時招集する。
4. 社員総会は、理事が招集する。招集通知は、会日の1週間前までに各社員に対して発する。ただし、社員全員の同意があるときは、招集の手続を経ることなく開催することができる。

### 第14条（議長）
社員総会の議長は、代表理事がこれに当たる。代表理事に事故があるときは、あらかじめ社員総会で定めた順序により他の理事が議長となる。

### 第15条（決議）
社員総会の決議は、法令又は本定款に別段の定めがある場合を除き、総社員の議決権の過半数を有する社員が出席し、出席した社員の議決権の過半数をもって行う。
2. 次に掲げる事項に係る決議（特別決議）は、総社員の半数以上であって、総社員の議決権の3分の2以上に当たる多数をもって行う。
   1. 社員の除名
   2. 理事の解任
   3. 定款の変更
   4. 解散
   5. その他法人法で特別決議を要するとされる事項

### 第16条（議決権）
各社員は、各1個の議決権を有する。

### 第17条（決議・報告の省略）
理事又は社員が社員総会の目的である事項について提案をした場合において、その提案につき社員（当該事項について議決権を行使することができるものに限る。）の全員が書面又は電磁的記録により同意の意思表示をしたときは、当該提案を可決する旨の社員総会の決議があったものとみなす。
2. 理事が社員の全員に対し社員総会に報告すべき事項を通知した場合において、当該事項を社員総会に報告することを要しないことにつき社員の全員が書面又は電磁的記録により同意したときは、当該事項の社員総会への報告があったものとみなす。

### 第18条（議事録）
社員総会の議事については、法令の定めるところにより議事録を作成し、これを主たる事務所に備え置く。

## 第4章 役員

### 第19条（役員の設置）
本社団法人に、理事[●]名以上[●]名以内を置く。
2. 本社団法人には、理事会及び監事を置かない。ただし、案件上の要請により、社員総会の決議をもって監事を置くことができる。

### 第20条（理事の選任）
理事は、社員総会の決議によって選任する。
2. 理事のうち少なくとも1名は、本社団法人、本合同会社、AM、匿名組合員、貸付人、売主その他本スキームの利害関係者から独立した者（以下「独立理事」という。）でなければならない。独立理事は、これらの者の役員・従業員・支配株主・親族等の利害関係を有しない者とする。
3. 独立理事に欠員が生じた場合又は独立理事がその要件を欠くに至った場合、本社団法人は、遅滞なく後任の独立理事を選任しなければならない。

### 第21条（理事の任期）
理事の任期は、選任後2年以内に終了する事業年度のうち最終のものに関する定時社員総会の終結の時までとする。
2. 補欠として選任された理事の任期は、前任者の任期の満了する時までとする。
3. 理事は、再任を妨げない。

### 第22条（理事の解任）
理事は、社員総会の特別決議によって解任することができる。ただし、独立理事の解任は、後任の独立理事が選任され就任することを条件としてその効力を生ずる。

### 第23条（代表理事）
理事が2名以上ある場合、代表理事[●]名を理事の互選により定める。
2. 代表理事は、本社団法人を代表し、その業務を執行する。
3. 独立理事は、原則として代表理事に就任しない。

### 第24条（理事の職務・善管注意義務）
理事は、法令及び本定款を遵守し、本社団法人のため忠実にその職務を行わなければならない。
2. 理事は、本社団法人の目的が第3条に定める限定目的にあること及び本社団法人が本合同会社の倒産隔離の頂点に置かれた器であることを常に認識し、本社団法人の独立性の維持に努めなければならない。

### 第25条（倒産隔離維持のための行為制限）
本社団法人及びその理事は、本社団法人の独立性並びに本合同会社及び本社団法人の倒産隔離を維持するため、次の各号に掲げる行為を行ってはならない。ただし、独立理事を含む理事全員の一致による承認を得た場合は、この限りでない。
1. 本合同会社の解散、清算、合併、組織変更又は事業の全部若しくは重要な一部の譲渡に係る社員としての同意又は議決権行使。
2. 本合同会社について、破産手続開始、民事再生手続開始、会社更生手続開始、特別清算開始その他これらに類する倒産処理手続開始の申立てを行い、又はこれに同意すること。
3. 本社団法人自らについて、前号に掲げる倒産処理手続開始の申立てを行うこと。
4. 本合同会社の定款のうち、その目的・倒産隔離・独立性の維持に関する条項の変更に係る同意。
5. 本社団法人による借入れ、債務の保証、担保の提供その他の与信又は信用供与。
6. 第3条に定める目的の範囲を超える事業又は資産の取得・処分。

2. 前項第2号及び第3号に掲げる倒産処理手続開始の申立てその他本合同会社の債権者を害するおそれのある行為については、独立理事の同意を欠く決議は、その効力を有しない。

### 第26条（アンチ・デフィシェンシー／請求の非追及）
本社団法人は、本合同会社の債権者その他の本スキームの関係当事者との間で別途合意した限度で、本社団法人の資産を超える債務について責任を負わないものとし、当該関係当事者は本社団法人の資産の範囲を超えて本社団法人に対する請求を行わず、かつ本社団法人につき倒産処理手続開始の申立てを行わない旨を、本社団法人は関係契約において確認するよう努める。
2. 本条は、本社団法人の独立性及び倒産隔離を補強する趣旨のものであり、その具体的内容は関係契約の定めによる。

### 第27条（報酬）
理事の報酬は、社員総会の決議によって定める。
2. 独立理事に対しては、その職務の対価として相当額の報酬を支払うことができる。

## 第5章 計算

### 第28条（事業年度）
本社団法人の事業年度は、毎年[●]月[●]日に始まり、翌年[●]月[●]日に終わる年1期とする。
2. 本社団法人の設立当初の事業年度は、本社団法人成立の日から[●]年[●]月[●]日までとする。

### 第29条（事業計画及び収支予算）
本社団法人の事業計画及び収支予算は、理事が作成し、社員総会の承認を受けなければならない。

### 第30条（計算書類）
本社団法人は、法令の定めるところにより、各事業年度に係る貸借対照表その他の計算書類を作成し、定時社員総会の承認を受けるものとする。

### 第31条（剰余金の不分配）
本社団法人は、剰余金が生じた場合であっても、これを社員に分配しない。本社団法人に生じた剰余金は、本社団法人の目的である事業のためにのみ使用する。

## 第6章 定款の変更・解散及び清算

### 第32条（定款の変更）
本定款は、社員総会の特別決議によって変更することができる。
2. 第3条（目的）、第5条（非営利性）、第20条第2項（独立理事）、第25条（倒産隔離維持のための行為制限）その他本社団法人の独立性及び倒産隔離に関する規定の変更については、独立理事を含む理事全員の同意を得た後でなければ、社員総会に付議することができない。

### 第33条（解散）
本社団法人は、次の各号に掲げる事由によって解散する。
1. 社員総会の特別決議
2. 社員が欠けたこと
3. 合併（本社団法人が消滅する場合に限る。）
4. 破産手続開始の決定
5. 法人法に定めるその他の事由

2. 本社団法人は、本合同会社の社員たる地位が存続する限り、原則として解散しないものとし、解散に係る社員総会の決議には独立理事の同意を要する。

### 第34条（清算）
本社団法人が解散したときは、法令の定めるところにより清算を行う。清算人は、社員総会の決議によって定める。

### 第35条（残余財産の帰属）
本社団法人が清算をする場合において有する残余財産は、社員総会の決議により、公益社団法人及び公益財団法人の認定等に関する法律第5条第17号に掲げる法人その他これに類する者に帰属させる。
2. 前項の規定にかかわらず、残余財産を社員に分配することはできない。
3. 前二項により処分されない残余財産は、国庫に帰属する。
