# 本スキームの共通前提・登場人物（各契約書ドラフトで統一使用）

本ファイルは、GK-TK（合同会社・匿名組合）スキームの各契約書ドラフトで共通して用いる
前提・当事者・定義語を定めたもの。各ドラフトはこの定義に整合させること。

## スキームの類型
- 日本の不動産を対象とする GK-TK（合同会社・匿名組合）スキーム。
- 不動産は**信託受益権化**されており、営業者（GK）は信託受益権を保有する（不動産特定共同事業法の適用回避・流通性確保のため）。

- 信託受益権（裏付け不動産＝●●県●●市●●所在の土地・建物。以下「本物件」）。

## 共通ルール
- 通貨は日本円。
- 未確定の金額・日付・料率・氏名等はすべて `[●]` で明示する。
- 各ドラフト冒頭に「本書式はドラフト（雛形）であり、実際の案件では弁護士・税理士・司法書士等の専門家によるレビューが必須である」旨の注記を置く。
- 文体は日本の実務契約書体（第○条／第○項／別紙）。Markdown見出しで構成。

## 資金・キャッシュフローの流れ（参考）
1. 匿名組合員 → 営業者：TK出資
2. 貸付人 → 営業者：ノンリコースローン
3. 営業者 → 売主：信託受益権売買代金の支払（信託受益権を取得）
4. 受託者 → PM会社：物件の賃貸管理委託／賃料収受
5. 受託者 → 営業者（受益者）：信託配当（賃料等）
6. 営業者：ローン元利返済 → AMフィー等費用 → TK利益分配（匿名組合員へ）
