## 1. GK-TK スキームとは

GK-TK スキームは、**合同会社（GK, Godo Kaisha）**を器（SPC）とし、**匿名組合（TK, Tokumei Kumiai）**契約を通じて
投資家から出資を集めて不動産等に投資する、日本の不動産証券化・私募ファンドの代表的ストラクチャー。

- **GK（営業者）** … 匿名組合の営業者。信託受益権を保有し、賃料収益を得て投資家に分配する。
- **TK（匿名組合）** … 投資家（匿名組合員）が営業者に出資する契約。投資家は業務執行に関与せず、有限責任・ノンリコース。
- **一般社団法人** … GK の唯一の社員（出資者）。GK を特定のスポンサーから切り離し、**倒産隔離（オーファン化）**を実現する。
- **不動産の信託受益権化** … 現物不動産ではなく**信託受益権**を保有することで、流通性の確保、不動産特定共同事業法の
  適用回避、流通税（不動産取得税・登録免許税）の軽減等を図る。
- 税務上、TK 分配金は営業者段階で損金算入され、**GK 段階で実質的に課税されない（導管性）**点がスキーム採用の主因。

### ストラクチャー図（概念）

```
        ┌─────────────────────┐
        │  一般社団法人●●      │  ← GKの唯一の社員（倒産隔離の頂点／オーファン化）
        └──────────┬──────────┘
                   │ 100%社員
                   ▼
   匿名組合員   ┌──────────────────────┐   貸付人（銀行）
  （投資家）───▶│  合同会社●●（GK）    │◀───ノンリコースローン
   TK出資       │   ＝匿名組合の営業者   │      （＋担保パッケージ）
        ▲       └──────────┬──────────┘
        │ TK利益分配         │ 信託受益権を保有
        │                    ▼
        │        ┌──────────────────────┐
        │        │ ●●信託銀行（受託者）  │  ← 本物件を信託財産として保有
        │        └──────────┬──────────┘
        │                    │ 賃貸管理を委託
   運用・監督                ▼
   ●●アセット      ┌──────────────────┐
   マネジメント ───▶│ PM会社（賃貸管理）  │
   （AM）  ◀────指図 └──────────────────┘
```

## 3. 契約締結・クロージングの標準的な順序（参考）

1. タームシート／LOI 合意、デューデリジェンス（DD）実施
2. SPC 設立：**一般社団法人 定款（03）→ 合同会社 定款（02）** 認証・設立登記、**職務執行者・事務委託（10）**
3. **信託設定（06）**：売主が本物件を信託銀行に信託し受益権化（既に信託済みの場合は不要）
4. 主要契約の締結：**匿名組合契約（01）／AM契約（04）／PM契約（07）／ローン契約（08）／担保契約（09）**
5. **信託受益権売買契約（05）**の締結
6. **クロージング**：TK出資払込・ローン実行 → 売買代金決済 → 受益権譲渡・対抗要件具備・担保設定・口座開設
7. 期中運用：賃料収受 → ウォーターフォールに従い返済・費用・分配 → 定期レポート
8. Exit：受益権/物件の売却、ローン返済、TK清算・分配、SPC の解散・清算

## 4. 各契約書の相互関係（コベナンツの整合に注意）

- **倒産隔離**：`02`（GK定款）・`03`（社団定款）・`10`（職務執行者）で、他業禁止・追加借入/担保の制限・
  解散/破産申立の制限（独立役員の同意要件）を一貫して規定する。
- **劣後関係**：TK出資（`01`）・AMフィー（`04`）・PMフィー（`07`）は、ローン（`08`）に劣後し、
  デフォルト時は支払停止となる旨を各契約で相互に整合させる。
- **担保と対抗要件**：受益権質権（`09`）は、信託契約（`06`）上の受託者の承諾・確定日付ある通知で対抗要件を具備する。
- **指図権**：物件運営はAM（`04`）が指図し、PM（`07`）・受託者（`06`）がこれに従う構図を各契約で明示する。
