# Phase 1 入力シート（会議調整の条件）

チャットに以下を貼って埋めてくれればOK（分かる範囲で。空欄はこちらで聞き返します）。

```
相手のメールアドレス:
会議の目的・件名:        例) 〇〇案件のキックオフ
所要時間:               例) 60分
候補を探す期間:          例) 6/24〜6/30 の平日
対面 or オンライン:      例) オンライン
会議室予約は必要?:       例) 不要（オンラインのため）
営業時間など除外条件:     例) 平日 10:00〜18:00、昼休み 12:00〜13:00 を除外
文面に入れたい補足:       例) 「ご都合いかがでしょうか」など。なければ空欄
あなたの名前(署名用):     例) 村田
```

## デフォルト（指定が無ければこれで進めます）
- 候補日は **3〜5件** 提示
- 営業時間 **平日 10:00〜18:00**、昼休み **12:00〜13:00** を除外、土日除外
- 文面は丁寧めの日本語ビジネスメール
- 返信時に「候補番号 or 日時」を明記してもらう案内を本文に追加
